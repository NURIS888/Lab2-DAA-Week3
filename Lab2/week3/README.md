# Week 3 — Solve and Analyze

This folder contains the Week 3 assignment: solving and analyzing two
LeetCode linked-list problems.

## Contents

- [`merge-two-sorted-lists/`](./merge-two-sorted-lists/) — solution,
  trace, and complexity analysis for
  [Merge Two Sorted Lists](https://leetcode.com/problems/merge-two-sorted-lists/description/).
- [`linked-list-cycle/`](./linked-list-cycle/) — solution, trace, and
  complexity analysis for
  [Linked List Cycle](https://leetcode.com/problems/linked-list-cycle/description/).

Each subfolder has its own `solution.py` (runnable with manual test cases
included) and its own `README.md` with the problem explanation, a
step-by-step trace of the algorithm, time/space complexity, and a
reflection on possible improvements.
